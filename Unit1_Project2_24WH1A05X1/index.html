Merge Sort Recursion Tree

Visualizing recursive division and merging of an array of 8 elements

1. Recursive Division

Merge Sort repeatedly divides the array into two smaller parts until each part contains only one element.

2. Merging Process

The individual elements are merged back together in sorted order.

Final Sorted Array

Time Complexity

Best Case: O(n log n)

Average Case: O(n log n)

Worst Case: O(n log n)

Space Complexity: O(n)

Algorithm Idea

Merge Sort follows the Divide and Conquer technique. First, the array is divided into smaller subarrays. Then the subarrays are sorted and merged to produce the final sorted array.
