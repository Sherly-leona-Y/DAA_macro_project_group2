# Merge Sort Recursion Tree

## Project Title
Recursion Tree for Merge Sort

## Description
This project is a web-based visualization of the Merge Sort algorithm.

It demonstrates how Merge Sort uses the Divide and Conquer technique. The array is recursively divided into smaller subarrays until each subarray contains one element. The subarrays are then merged back together in sorted order.

## Features

- Enter an array of 8 numbers.
- Visualize the recursive division of the array.
- Display the recursion levels.
- Visualize the merging process.
- Display the final sorted array.
- Show the time and space complexity.
- Simple and easy-to-understand interface.
- Responsive web design.

## Technologies Used

- HTML
- CSS
- JavaScript

## Algorithm

Merge Sort follows these steps:

1. Divide the array into two halves.
2. Recursively divide the left half.
3. Recursively divide the right half.
4. Merge the sorted halves.
5. Continue until the complete array is sorted.

## Example

Input:

`8, 3, 5, 1, 7, 2, 6, 4`

Output:

`1, 2, 3, 4, 5, 6, 7, 8`

## Complexity Analysis

- Best Case: O(n log n)
- Average Case: O(n log n)
- Worst Case: O(n log n)
- Space Complexity: O(n)

1. Open the project folder in Visual Studio Code.
2. Open `index.html`.
3. Run the file using Live Server.
4. Enter 8 numbers.
5. Click **Generate Recursion Tree** to visualize Merge Sort.
